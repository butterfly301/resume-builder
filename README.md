# 简历编辑器

固定模板的本地简历编辑与 PDF 导出程序。每份简历独立保存在 `data/resumes/<简历id>.json`，导出的 PDF 同时保存到 `exports`。

## 启动

双击 `start.bat`。首次运行会自动安装依赖并构建，随后打开默认浏览器访问 `http://127.0.0.1:4178`。使用期间保持命令行窗口开启，关闭窗口即停止服务。

其他启动方式：

```powershell
# 开发模式：前端热更新（端口 5173）+ API 服务（端口 4178）
npm run dev

# 生产模式：构建后启动
npm run build
npm start
```

## 界面布局

- 左侧简历列表：新建、复制、重命名、删除简历。删除后有 8 秒撤销期
- 中间编辑区：个人信息、教育信息、内容板块、排版调整
- 右侧 A4 实时预览：内容与排版修改即时生效。点击预览中的板块或条目，编辑区自动滚动并高亮对应位置

## 编辑内容

**个人信息与教育**：姓名、求职岗位、意向城市、手机号、邮箱、微信、个人网站、出生年月、照片（3.5MB 以内），以及毕业届别、专业、学校。留空的字段不出现在预览中。

**内容板块**分两类，可自由增删和拖拽排序：

- 经历型：条目包含标题（公司或项目名）、职责角色、日期、外链、分隔符样式，以及多条要点
- 技能列表型：每条可选用"项目符号"或"摘要行"两种样式

三个层级（板块、条目、要点）都支持拖拽排序。要点支持加粗与插入链接。

**快捷键**：Ctrl+Z 撤销，Ctrl+Y 重做。

## 保存与快照

- 自动保存：停止编辑约 1 秒后写入 `data/resumes/<简历id>.json`，顶部指示器显示保存状态
- 外部修改检测：每 2 秒检查一次磁盘文件，本地没有未保存改动时自动载入磁盘上的最新版本。因此直接修改 JSON 文件后，编辑器会在数秒内同步，无需重启
- 版本快照：在"版本快照"卡片中创建、恢复、删除。快照保存在该简历 JSON 的 `snapshots` 字段，随文件一起落盘，适合在投递不同岗位前留存当前版本

## 排版调整

排版卡片中的修改即时预览，并保存在简历 JSON 的 `layout` 字段中，每份简历各自独立：

板块间距、条目间距、摘要行间距、标题间距、点间距、行间距、正文字号、板块标题字号、条目标题字号、上/下/左/右边距、照片宽高、主题色。

## 导出 PDF

点击顶部"导出 PDF"：PDF 保存到 `exports/姓名-岗位-手机号.pdf`，同时通过浏览器下载一份。

导出前会做溢出检查：某条经历的高度超过一页时禁止导出，需精简该条内容后重试。

打印视图地址为 `http://127.0.0.1:4178/?print=1&resume=<简历id>`，可直接在浏览器中打开查看分页结果。

## 配置

| 环境变量 | 作用 | 默认值 |
| --- | --- | --- |
| `PORT` | 服务端口 | `4178` |
| `RESUME_BROWSER_PATH` | 导出 PDF 用的浏览器可执行文件路径 | 依次探测本机 Edge、Chrome |

## 文件结构

```
resume-builder/
├── data/resumes/   # 简历 JSON，每份一个文件，直接编辑会被编辑器自动同步
├── exports/        # 导出的 PDF
├── dist/           # 前端构建产物
├── dist-server/    # 服务端构建产物
├── server/         # Express API 源码
├── src/            # React 前端源码
└── start.bat       # 一键启动脚本
```
